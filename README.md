# (unofficial) UJ thesis search

The official thesis [search tool](https://ruj.uj.edu.pl/communities/531510cc-c3a7-4cd1-a5af-28749788f581) provided by the university is bad. This little project aims to provide a better alternative. 

Hosted by Github pages [here](https://pug0r.github.io/better-thesis-search/).

Allows you to filter by thesis type, year, department and language. 

Full text search on title, author, reviewers, department, keywords and language.
